# Early C Programming Practice

This repository contains C programs I originally wrote in 2024, near the beginning of my software engineering journey.

At the time, I was still learning programming fundamentals and was not familiar with Git or GitHub, so I stored these files locally on a flash drive. I recovered them in November 2026 and uploaded them here to preserve my early work and document my progress as a developer.

## Topics Covered

The programs include beginner exercises involving:

- Variables and user input
- Conditional and switch statements
- For loops
- Basic calculations
- Pattern generation
- Word and text checking
- Simple problem-solving exercises

## Important Note

These files largely reflect my original 2024 knowledge and coding style. They may not follow all the practices I use today, but I have kept them as evidence of where my programming journey began and how my skills have developed since then.
